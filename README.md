# NextJs Finance Calculator

A finance calculator built with Next.js.

## Getting Started

This repository is currently a starter. Scaffold the app with:

```bash
npx create-next-app@latest .
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- [Next.js](https://nextjs.org/)
- TypeScript
- Tailwind CSS
